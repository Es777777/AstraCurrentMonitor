Camera Current Monitor v1.3.3

The blue digits on the upper display row are voltage in volts (V). The red
digits on the lower row are current in amps (A). The interface marks each row
with a separate color and reading box.

Camera setup
1. Connect any USB camera supported by Windows through DirectShow or MSMF.
2. Click Refresh Camera List and choose a detected camera.
3. Choose a backend and requested resolution, then click Connect Camera.
4. Use Auto Locate Two Rows. If needed, draw separate regions for voltage and
   current. Keep the complete digits inside the preview with a small margin.
5. Check the displayed values and decimal point against the physical meter.

Measurement
The default cycle captures for 5 seconds, waits 10 seconds, then starts again.
Each saved row records the peak current, voltage at that peak, maximum voltage,
frame counts, quality, status, and an evidence image when available. Export the
table as CSV. Simulated demo readings are marked and are not real measurements.

Packages
Offline package: extract the complete ZIP and run CameraCurrentMonitor.exe.
It contains the full runtime and works without internet or Python installed.

Online package: extract its ZIP and run Install-Online.ps1 in PowerShell. The
installer checks Windows architecture and disk space, downloads the offline
runtime from this project's GitHub release, verifies the published SHA-256,
installs under the current user's LocalAppData Programs folder, and launches.
An internet connection is required for the online installer only.

On first use, verify several known readings. Blurred, clipped, overexposed, or
ambiguous digits are rejected. Accuracy depends on camera focus, exposure,
display style, frame rate, and mounting. The software cannot recover changes
that were never captured by the camera.
