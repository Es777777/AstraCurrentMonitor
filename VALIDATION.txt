Camera Current Monitor v1.3.3 validation summary

- Automated unit tests cover camera queue handling, recognition, measurement
  timing, peak handling, and durable storage.
- The migrated ten-image regression set checks blue upper-row voltage and red
  lower-row current readings.
- Layout smoke checks run at 1380x940, 1100x780, and 900x680; action buttons
  remain outside the preview bounds and the left work area scrolls vertically
  when the window is shorter than its content.
- The packaged executable is tested with the synthetic demo measurement flow.
- The software maximum-current recognition threshold defaults to 999999 A; it
  filters recognized values and is not a meter range or peak-current cap.
- The offscreen UI screenshot uses the real PyQt5 window and the application's
  generated two-row test image. Its displayed values are simulated, not measured.

Camera-specific accuracy depends on the target computer and display. Verify
against the physical instrument before relying on the readings.
